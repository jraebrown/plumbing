Stage 7: Radiator 3 and Return Route

Next →
PLANNING DOCUMENT — The valve sides, flow direction, terminal arrangement and fittings must be confirmed on site by the heating engineer before work starts.
Do not directly join the flow and return mains. Radiator 3 is intended to provide the hydraulic connection between them through its two valves. This is a proposed layout only.

How the proposed route works

The flow main is proposed to continue from the earlier radiator branches to one valve on radiator 3. The return main is proposed to connect to the other valve on radiator 3 and then run back alongside the flow route to the boiler.

“Terminal” means there are no further radiator branch tees beyond radiator 3 on this proposed route. It does not mean that the return pipe ends there; the return main must remain continuous back to the confirmed boiler return connection.

Engineer-confirmed sequence

  1. Confirm which radiator valve is on the flow side and which is on the return side; do not infer this from left/right position alone.
  2. Confirm the required bends, supports, clearances, valve type and access arrangements.
  3. Connect each main only after the engineer has approved the route and the push-fit preparation has been completed to manufacturer instructions.
  4. Verify the full return route back to the boiler before pressure testing; do not regard radiator 3 as an isolated pipe end.

Materials status

Previous references to a fixed elbow count, retailer code and quantity are provisional estimates. Confirm the exact fitting product, compatibility and quantity against the final measured route and manufacturer documentation before purchase.
