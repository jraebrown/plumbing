Stage 7: Final Radiator and Return Route

Next →
Important: Visual inspection cannot establish that a system is leak-free before it is filled and tested. This stage is a visible-installation check only; do not describe it as a leak test.

Purpose

Complete the final radiator connection and record the continuous return route back to the appliance connection point. The radiator is part of the heating circuit; it is not a point at which the return pipe terminates.

More detail on return route

Follow the return pipe from the final radiator back towards the appliance area, checking for hidden tees or changes of direction. The return should remain a continuous path that eventually reaches the confirmed boiler return connection rather than ending at the radiator or disappearing behind boxing without recorded access.

Personal check

More detail on checks

Instead of trying to prove the system is leak-free at this stage, concentrate on confirming the visible layout against the intended design, noting any uncertainty or tight access that could affect future inspection or repair. Use the notes box for sketches or photo references that will help the plumber review the route.

Complete when: All connections visually checked, with no visible damage or assembly concerns, and ready for review.
