Stage 7: Final Radiator and Return Route

Next →
Important: Visual inspection cannot establish that a system is leak-free before it is filled and tested. This stage is a visible-installation check only; do not describe it as a leak test.

Purpose

Complete the final radiator connection and record the continuous return route back to the appliance connection point. The radiator is part of the heating circuit; it is not a point at which the return pipe terminates.

Personal check

Complete when: All connections visually checked, with no visible damage or assembly concerns, and ready for review.

Stage notes

PLANNING AND RECORDING AID — final configuration subject to competent on-site review
