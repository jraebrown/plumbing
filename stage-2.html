Stage 2 of 10: Route Measurement
02
Route Measurement
⏱ 2 hrs Easy
🎯 Stage Goal:

Physically measure flow and return routes on site across all rooms with a tape measure to determine exact pipe quantities.

⚠️ Watch-out:
Do NOT rely on floor plan room dimensions alone! Measure vertical drops, wall offsets, and radiator valve centers on site.
✅ Complete When:
All route segments measured on site, recorded in notebook, totaling ~22.8m one-way / ~45.6m both pipes, and 17x3m lengths (51m) pipe ordered.
⚠️ DO NOT SKIP VERTICAL DROPS: For every horizontal meter, remember both parallel flow AND return pipes must be run. Total pipe required is double the one-way route distance!

Step-by-Step Instructions

1
Measure boiler vertical drop from underside stubs to floor skirting level (~1.2m x 2 = 2.4m).
2
Measure Kitchen wall run along skirting perimeter (~2.7m x 2 = 5.4m).
3
Measure Reception Room width and approach to Radiator #1 (~6.4m x 2 = 12.8m).
4
Measure Bedroom 1 approach and bottom wall to Radiator #2 (~3.6m x 2 = 7.2m).
5
Measure Bedroom 2 run through partition to Radiator #3 terminal (~2.5m x 2 = 5.0m).
6
Add wall penetrations (~0.9m) and radiator branch vertical tails (~1.5m x 2 = 3.0m).
7
Sum total route (~22.8m one-way / ~45.6m both pipes) and add 10% waste allowance -> **17 x 3m lengths = 51m**.
📏 Order Formula: One-Way Route (22.8m) × 2 = 45.6m + 10% Cutting Waste Allowance = ~50m total -> Order 17 lengths of 3m Wednesbury 15mm copper pipe (Screwfix Code: 98683).
