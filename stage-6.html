Stage 6: Radiator Branchwork

Next →
Review point: Keep all new branches and joints visible. Confirm the final branch layout, pipe sizes, valve orientation, fitting compatibility and support arrangement against the actual system before enclosing or testing.

Purpose

Install the planned radiator branches so each radiator is connected between the confirmed flow and return routes. Do not rely on a diagram, assumed tee size, fixed fitting quantity or left/right valve position in place of on-site verification.

More detail on branch layout

In a two-pipe layout each radiator takes one branch from the heating flow route and one branch from the heating return route. The mains continue through their tees to the rest of the system. Use tracing on the actual installation to confirm that each radiator bridges two separately identified routes rather than looping back into the same run.

Personal check

More detail on checks

Route continuity: trace each main through its tees to confirm it does not terminate at a radiator. Branch connections: follow each radiator valve back to its tee and confirm that one branch reaches the flow route and the other the return route.

Fitting preparation: confirm that tube ends were cut square, deburred, clean, undamaged near the sealing area, fully inserted to the maker’s stated depth and are matched to an approved fitting and pipe combination.

Complete when: Radiator branches installed, visible and ready for review.
